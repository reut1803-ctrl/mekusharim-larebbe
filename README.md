# מקושרים לרבי – שאלון היכרות + ניהול מועמדים

מערכת CRM פנימית ושאלון היכרות עבור "מקושרים לרבי", בנויה ב-Next.js ו-Tailwind CSS,
מותאמת 100% למובייל, בעברית מלאה.

**מאגר עצמאי לגמרי.** הקוד כאן עומד בפני עצמו — אין לו שום תלות במאגר אחר,
לא בזמן בנייה ולא בזמן ריצה.

## המגירה בענן – נפרדת וריקה

המערכת מתחברת לאותו פרויקט Firebase (`kehila-itcha`), אבל **כל אוספי הנתונים
שלה נושאים את הקידומת `mekusharim_`**:

| האוסף בענן | תפקיד |
| --- | --- |
| `mekusharim_candidates` | מועמדים |
| `mekusharim_reps` | נציגים |
| `mekusharim_tasks` | משימות |
| `mekusharim_matches` | התאמות |
| `mekusharim_recordings` | מטא-דאטה של הקלטות |
| `mekusharim_recordingBlobs` | קובצי האודיו עצמם |
| `mekusharim_logs` | יומן פעילות |
| `mekusharim_meta/config` | הקדמה, שאלות וסיסמאות |

הקידומת מוגדרת במקום אחד בלבד — `lib/config.js` — וכל גישה למסד עוברת דרך
הפונקציה `col()` שם. לכן:

- המערכת מתחילה **ריקה לחלוטין**: אין מועמדים, אין נציגים, אין הגדרות קודמות.
- היא **לא קוראת ולא כותבת** לנתונים של מערכת אחרת באותו פרויקט.
- גם המפתחות שנשמרים בדפדפן (התחברות, טיוטות טפסים) נושאים את אותה קידומת,
  כך שאין התנגשות בין המערכות באותו מכשיר.

בכניסה הראשונה נוצר אוטומטית מסמך ההגדרות עם השאלון ברירת המחדל
וסיסמת מנהלת התחלתית `admin1234` — **יש להחליף אותה מיד** במסך הניהול.

### הרשאות ב-Firestore

אם כללי ההרשאות (Rules) בפרויקט מוגדרים לפי שמות אוספים מפורשים, יש להוסיף להם
את האוספים בקידומת `mekusharim_` כדי שהמערכת תוכל לקרוא ולכתוב.
אם הכללים כלליים (למשל מתירים לכל משתמש מחובר), לא נדרש שינוי.

## מה יש במערכת

**צד המועמד (השאלון):**
- מסך פתיחה עם הלוגו הגדול ובחירת מסלול (בחור / בחורה).
- שאלון מלא (פרטים אישיים, תמונה, שאלות פתוחות, אנשי קשר). כל השדות חובה.
- לאחר השליחה לא ניתן לערוך. מסך סיום עם הודעת תודה.

**מערכת הניהול (כניסה דרך "כניסת צוות" במסך הפתיחה):**
- **מנהלת:** רואה את כל המידע, מוחקת כפילויות, משייכת מועמדים לנציגים, עורכת
  טופסי מועמדים ואת שאלות השאלון.
- **נציג:** רואה עמודה משלו עם המועמדים המשויכים אליו.
- כרטיס מקוצר (תמונה, שם, גיל, מגדר, נציג) וכרטיס מורחב (הטופס המלא).
- **מידע רגיש:** גלוי רק לנציג ולמנהלת.
- **ייצוא:** העתקה ללוח והורדת PDF – נקיים, ללא מידע רגיש וללא טלפוני בירורים.
- **פעולות מתקדמות:** הוספת מועמד, משימות עם תאריך יעד, התאמות (Match) עם
  "הצעד הבא", יומן מעקב וכפתור יצירת קשר בוואטסאפ, הקלטות שמע ויומן פעילות.
